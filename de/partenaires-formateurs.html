So funktioniert es

Eine Partnerschaft in drei Schritten.

Sie konzentrieren sich auf die Schulung. Atelier CAL übernimmt Verkauf, Fertigung, Versand und Kundendienst.

01

Partnerkonditionen

Erhalten Sie Konditionen, die zu Ihrem Profil, Ihrer Tätigkeit und dem Einsatz der Maschine in Schulungen passen.

02

Persönlicher Code

Teilen Sie einen eindeutigen Code, mit dem Anfragen zugeordnet und vereinbarte Kundenvorteile gewährt werden können.

03

Nachvollziehbare Provision

Für jeden Verkauf aufgrund Ihrer Empfehlung erhalten Sie eine Provision.

Für wen?

Profis, die ihr Handwerk zeigen.

Das Programm richtet sich an selbstständige Schulungsleiter, Werkstätten, Vorführer, Dozenten und private Einrichtungen, die ein professionelles Gerät unter realen Bedingungen vorstellen möchten.
