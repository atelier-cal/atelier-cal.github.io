2. Erhobene Daten

Im Rahmen seiner Tätigkeit kann Atelier CAL folgende Daten erheben:

  • Vor- und Nachname
  • E-Mail-Adresse
  • Postanschrift
  • Rechnungsdaten
  • Navigationsdaten (IP-Adresse, Browsertyp)

Zahlungsdaten werden ausschließlich von der sicheren Plattform Stripe verarbeitet. Atelier CAL hat niemals Zugriff auf vollständige Bankdaten.

3. Zweck der Verarbeitung

Die Daten werden erhoben für:

  • die Bearbeitung von Bestellungen
  • die Rechnungsstellung
  • die Kundenbeziehung
  • die Erfüllung gesetzlicher und buchhalterischer Pflichten

4. Speicherdauer der Daten

Die Daten werden nur so lange aufbewahrt, wie es für die Zwecke, für die sie erhoben wurden, erforderlich ist, und entsprechend den gesetzlichen Verpflichtungen.

5. Weitergabe von Daten

Personenbezogene Daten werden weder verkauft noch an Dritte weitergegeben.

Sie können nur an Dienstleister übermittelt werden, die für die Erbringung der Leistungen erforderlich sind, insbesondere:

  • Stripe (Zahlung)
  • Transportunternehmen (Lieferung)

6. Rechte der Nutzer

Gemäß der Datenschutz-Grundverordnung (DSGVO) hat jede Person das Recht auf:

  • Auskunft
  • Berichtigung
  • Löschung
  • Widerspruch

Jede Anfrage kann gesendet werden an: 📧 contact@atelier-cal.fr

7. Cookies

Die Website Atelier CAL kann Cookies verwenden, die für ihr ordnungsgemäßes Funktionieren und zur Reichweitenmessung erforderlich sind. Der Nutzer kann seinen Browser so einstellen, dass er sie ablehnt.
