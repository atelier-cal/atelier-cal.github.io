Comment ça marche

Le partenariat est pensé pour les formateurs : vous utilisez la machine en formation, vous la recommandez naturellement, et les ventes sont suivies via votre code.

  • 1) Conditions partenaires Accès à la machine SRC à conditions préférentielles (selon profil et activité).
  • 2) Code de parrainage personnel Un code unique à partager (remise appliquée automatiquement au client).
  • 3) Commission sur les ventes Vous percevez une commission pour chaque vente réalisée avec votre code.
